# Draft Notes

This directory holds rough project notes, evolving plans, literature notes, critique rounds, and intermediate audits.

Use it for work that is still changing. Keep mature summaries, final-facing material, and stable reproduction notes in `final/`.

Key files:

- `live_plan.md`: current high-level plan and active scope.
- `iterative_research_record.md`: running research and decision log.
- `research_journal.md`: reading notes and design observations.
- `literature_notes.md`: source notes and related-work material.
- `main_pilot_result_audit.md`: current pilot-result audit.
