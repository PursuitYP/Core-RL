# Reports 中文说明

`final/reports/` 是正式 proposal 报告区。每个 proposal 文件夹的主文件是 `report.md`，中文辅助文件是 `report_zh.md`。早期拆散的 `proposal_template.md`、`results.md`、`critique.md`、`reproduction.md` 已移动到 `final/archive/`，避免审阅者需要拼装故事。

当前报告分为两类：`proposals/` 下是十三个普通独立 proposal；`integrated/` 下是三个更大的综合型独立 proposal。它们都遵守 no replay buffer、no deep network、online continual learning 的项目约束。
