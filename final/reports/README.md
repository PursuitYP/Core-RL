# Proposal Reports

This directory contains final-facing standalone reports.

- `integrated/`: three larger independent Core-RL studies that combine several course themes into richer research questions.
- `proposals/`: thirteen independent proposal reports from the broader project portfolio.

Each proposal folder is intentionally simple: the primary file is `report.md`. Older supporting fragments such as separate `results.md`, `critique.md`, `proposal_template.md`, and `reproduction.md` were moved to `final/archive/` so the review path is not fragmented.
