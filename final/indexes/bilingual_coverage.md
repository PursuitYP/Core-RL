## Archive Materials

Archive files are not the main review path, so they are not all translated one by one. The important archive entry points and proposal templates have bilingual support:

- `final/archive/README.md` and `final/archive/README_zh.md`
- `final/archive/proposal_fragments/README.md` and `final/archive/proposal_fragments/README_zh.md`
- `final/archive/integrated_fragments/README.md` and `final/archive/integrated_fragments/README_zh.md`
- every `final/archive/proposal_fragments/*/proposal_template.md` and matching `proposal_template_zh.md`
- deferred off-policy GVF note `report.md` and `report_zh.md`

## Consistency Rule

English and Chinese versions are expected to carry the same substantive content. When a result or status changes, update both versions in the same edit. If a conflict is found, trust the current final-facing report plus `final/indexes/results.md` for evidence, then update the mismatched language counterpart immediately.
