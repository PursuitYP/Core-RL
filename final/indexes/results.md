# Current Result Index

This file is the final-facing evidence index. Older result directories remain on disk for auditability, but only the entries below should be cited as current candidate evidence unless a newer run supersedes them. Independent proposal reports are indexed in `final/reports/proposals/README.md`; integrated reports are indexed in `final/reports/integrated/README.md`; reproduction commands are in `final/indexes/reproduction.md`.

Older main pilots generally use suite `main`, seeds `0-4`, and `5000` online steps. Several July 9 extended runs now use seeds `0-19` and `20000` online steps; those are explicitly marked with `_extended` result paths. Statistics below are seed-tail summaries from `condition_summary.json`, not single-seed screenshots. The report named `GVF Predictive State` maps to implementation/config/result key `useful_gvfs_state`.

As of the latest artifact audit on 2026-07-09, the scale fixed-condition extended job, output-fairness audit, reward-centered sensitivity sweep, and Dyna drift sweep have all written standard artifacts and are current evidence. Older failed job IDs `21581151`, `20998802`, and `18940577` failed with `/data/yupeng/conda_envs/core-rl/bin/python: No such file or directory` inside the rjob container; keep them audit-only and out of current evidence.

## Result Artifact Policy

Every new result directory should contain `metrics.csv`, `summary.json`, `condition_summary.json`, `config_used.json`, and `manifest.json`. Final claims should use `*_seed_tail` statistics from `condition_summary.json`, not file-order tail averages. The current summary schema is `seed_tail_v1`. A directory without all five standard artifacts is not evidence, even if it was created by a running CPU job.

Report-ready figures for the three integrated proposals were regenerated with `experiments/alberta_core_rl/scripts/plot_report_figures.py` because the original many-series learning-curve legends compressed the plotting area. The new figures are stored as `figures/report_*.png` under each integrated result directory.
