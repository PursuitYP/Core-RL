# Indexes 中文说明

`final/indexes/` 负责导航、结果、复现和需求覆盖，不替代正式 report。中英文索引应保持内容一致；如果索引和正式报告冲突，以当前 `final/reports/**/report.md` 与 `final/indexes/results.md` 为准。

关键文件：`results_zh.md` 汇总当前结果和数字；`reproduction_zh.md` 汇总环境和命令；`status_zh.md` 说明当前项目状态；`requirements_audit_zh.md` 对照原始用户需求；`report_section_audit_zh.md` 机械检查 17 个正式报告缺哪些关键章节；`project_plan_zh.md` 记录当前计划快照；`revise_plan_20260709_zh.md` 保存本轮大版本 revise 计划和调研资料；`reviewer_audit_zh.md` 记录多角色审查意见和处理状态；`session_resume_20260709_1830.md` 和 `session_resume_20260709_2146.md` 记录长任务恢复点。若索引与 report 冲突，以 `final/reports/**/report.md` 和 `final/indexes/results.md` 为准。

`bilingual_coverage_zh.md` 记录哪些重要文档已经有中英文对应版本，并说明后续更新时应同步维护两种语言。
