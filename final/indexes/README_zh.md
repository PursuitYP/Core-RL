# Indexes 中文说明

`final/indexes/` 负责导航、结果、复现和需求覆盖，不替代正式 report。英文文件仍是 canonical 索引，中文 `_zh.md` 文件用于快速审阅。

关键文件：`results_zh.md` 汇总当前结果和数字；`reproduction_zh.md` 汇总环境和命令；`status_zh.md` 说明当前项目状态；`requirements_audit_zh.md` 对照原始用户需求；`project_plan_zh.md` 记录当前计划快照；`reviewer_audit_zh.md` 记录多角色审查意见和处理状态。若索引与 report 冲突，以 `final/reports/**/report.md` 和 `final/indexes/results.md` 为准。

`bilingual_coverage_zh.md` 记录哪些重要文档已经有中英文对应版本，并说明后续更新时应同步维护两种语言。
