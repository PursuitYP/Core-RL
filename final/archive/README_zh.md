# Archive 中文说明

`final/archive/` 保存历史草稿、早期 proposal fragments、旧报告和暂缓想法，用于审计项目如何演化。它不是当前主阅读路径。

- `legacy/`：旧版综合报告、proposal dossiers 和 gate review。
- `proposal_fragments/`：十三个普通 proposal 的早期模板、结果片段、批评记录和复现片段。
- `integrated_fragments/`：三个综合型 proposal 的早期证据图、实验计划、批评记录和复现片段。
- `deferred_integrated/`：当前没有纳入三大综合 proposal 的更大想法。

当前正式 claim 应使用 `final/reports/**/report.md`、对应中文 `report_zh.md`、以及 `final/indexes/results.md`。如果 archive 片段与当前报告冲突，以当前报告和结果索引为准。
