# Archive

This folder keeps historical drafts and supporting fragments for auditability.

- `legacy/`: older overview reports, proposal dossiers, and gate-review documents.
- `proposal_fragments/`: per-proposal files that were useful during development but are no longer the main review path.
- `integrated_fragments/`: supporting files for the three integrated proposals.
- `deferred_integrated/`: larger ideas that are not part of the current three integrated proposal set.

Do not use archived fragments as the primary source for current claims. Use `final/reports/**/report.md` and `final/indexes/results.md`.
