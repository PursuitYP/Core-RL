# Proposal Fragments 中文说明

本目录保存十三个普通 proposal 的历史支持文件，包括早期 proposal template、result snippet、critique note 和 reproduction snippet。当前主阅读路径已经改为 `final/reports/proposals/<proposal>/report.md` 和 `report_zh.md`。

每个 proposal 目录中的 `proposal_template_zh.md` 是中文审阅版，说明该模板为何归档、当前正式报告路径、当前结果路径、当前状态、缺失细节和升级条件。其他 `critique.md`、`results.md`、`reproduction.md` 多为历史片段，只有在追溯演化过程时才需要阅读。
