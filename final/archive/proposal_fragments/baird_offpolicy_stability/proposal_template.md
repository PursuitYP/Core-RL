# Course Project Proposal

**Team Members:** Core RL Course Project

**Working Direction / Title:** Off-Policy TD Stability in a Baird-Style Counterexample

## What do you want to understand?

Why ordinary off-policy semi-gradient TD can fail when bootstrapping, function approximation, and off-policy sampling interact. The focused RL question is: which update geometry stabilizes value prediction in the smallest classic deadly-triad diagnostic?

## What setting or testbed will you use?

Baird's counterexample with linear features, behavior/target policy mismatch, and a single continuing trajectory.

## What will you examine?

Off-policy TD and gradient-corrected alternatives such as TDC across step sizes. The experiment is diagnostic rather than a control benchmark.

## What will you look at?

Weight norm, value estimates, divergence flags, and alpha sensitivity. A useful figure should show the stability region rather than only a final scalar score.

## Expanded Template Details

### Focused RL Problem

This proposal is a continuing prediction problem rather than a control benchmark. A stream of states is generated by a behavior policy that differs from the target-policy distribution implicit in the TD target. The learner uses linear features and bootstrapping. The intended pressure is the classic deadly triad: function approximation, bootstrapping, and off-policy sampling.

### Agent And Update

The baseline semi-gradient off-policy TD update is compared with a gradient-corrected method such as TDC. The report must specify the feature vectors, target transition, behavior sampling probability, importance ratio, alpha grid, and secondary-weight step size for TDC-style correction.

### Experiment Plan

Run each algorithm over multiple step sizes and seeds. The experiment should log the full online trajectory rather than only final weights, because the scientific question is stability over time. A stricter final version should verify the canonical Baird setup against a textbook/reference implementation before making broad claims.

### Metrics And Decision Rule

Primary metrics are weight norm, divergence fraction by seed, time to divergence, TD error, and value estimates for upper/lower states. A positive result is not high reward; it is a clear separation between unstable semi-gradient behavior and stabilized corrected updates.

### Fallback

If canonical verification remains uncertain, this proposal should stay a supporting diagnostic warning about off-policy instability rather than a main submission topic.

## Additional Writing Guidance
