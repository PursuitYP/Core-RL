# Critique: Doorway Options

## Reviewer Objections

- Options must be evaluated by real environment steps, not decision steps.
- Transfer is premature unless options first help in a fixed-goal sanity task.
- Hand-coded options test utility, not option discovery.
- Long options can impose commitment cost under changing goals.

## Revisions Already Made

- Added environment-step accounting.
- Added SMDP-style updates, option usage, and duration metrics.
- Reframed current result as a negative option-utility test.

## Next Required Iteration

- Add fixed-goal Four Rooms sanity test.
- Sweep option duration caps.
- Separate exploration benefit from commitment cost.
- Only retest transfer after fixed-goal utility is established.
