# Integrated Proposal Fragments 中文说明

本目录保存三个综合型 proposal 的历史支持文件，包括 proposal template、evidence map、experiment plan、critique log、reproduction snippet 和 result snippet。当前主阅读路径是 `final/reports/integrated/<proposal>/report.md` 和 `report_zh.md`。

这些 fragment 的价值在于审计：可以看到每个综合课题如何从多个较小 proposal 和多轮批评中形成。正式结果、图表和结论应以当前 integrated report 和 `final/indexes/results.md` 为准。
